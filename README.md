# ALMMA WEB V1

Static responsive prototype for ALMMA — Marketing & Creative Studio.

## Files
- index.html
- styles.css
- script.js
- assets/

## Deploy
This project can be uploaded to GitHub and deployed as a static site with Cloudflare Pages / Workers Static Assets.

## V1 notes
The project thumbnails are temporary crops from the analytics screenshots supplied for prototyping. Replace the files in /assets with original high-resolution photos/videos later while keeping the same filenames, or update the paths in index.html.

The language switcher supports FR / EN / ES.
Animations include scroll reveals, counters, marquee, parallax and micro-interactions.
prefers-reduced-motion is respected.
